# Hybrid Camera Unicycle: reproducible code for bearing-invariance analysis

This repository contains the Python implementation, verification routines, and
reference outputs used to reproduce the numerical results reported in the paper
**“Bearing Invariance and Robust Disturbance Thresholds for Hybrid Camera-Based
Unicycle Stabilization,”** accepted for publication in *IEEE Control Systems
Letters*.

The repository implements the controller and hybrid update rules analyzed in the
paper together with the numerical studies for core invariance, strict FOV
confinement, Lyapunov safe sets, persistent yaw-rate disturbances, measured
bearing error, sampled bearing updates, and conservatism analysis.

No proprietary data or external dataset is required.

## Project map

| Path | Purpose |
|---|---|
| `codes/model.py` | reduced and full closed-loop models; forward-Euler and hybrid integrators |
| `codes/theory.py` | core-invariance, strict-FOV, Lyapunov, and disturbance quantities |
| `codes/certify.py` | numerical checks of the analytical results |
| `codes/experiments.py` | numerical protocols for the bearing-barrier, disturbance-threshold, and Lyapunov safe-set studies |
| `codes/figures.py` | figure generation for the nominal numerical studies |
| `codes/implementation_errors.py` | measured-feedback dynamics, error budget, and sampled-bearing bound |
| `codes/sampled_simulation.py` | zero-order-held and asynchronous-coordinate simulations |
| `codes/implementation_experiments.py` | strict-FOV sweep, measured-error thresholds, sampled checks, and `theta0=0` conservatism audit |
| `codes/verify_implementation.py` | symbolic and numerical verification of the implemented equations and bounds |
| `run_project.py` | integrated reproduction entry point |
| `reference_results/` | precomputed reference outputs for comparison |
| `results/` | outputs generated by local runs |

## Environment

Requires Python 3.10 or later; tested with Python 3.13.5.

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Run all commands from the repository root, the directory containing
`run_project.py` and the `codes/` package.

## Run the complete project

Run the following stages as separate commands:

```bash
python run_project.py implementation --out results
python run_project.py nominal --quick --out results
python run_project.py audit --out results
python run_project.py collect --out results
```

These commands reproduce the implementation-level tables and strict-FOV sweep,
the reduced nominal certification checks, the bearing-barrier,
disturbance-threshold, and Lyapunov safe-set studies, and the symbolic/numerical
audit.

To run the full nominal certification grids, replace the second command with:

```bash
python run_project.py nominal --out results
```

The full nominal certification is more computationally expensive. The Lyapunov
safe-set study uses the deterministic 61 x 61 initial-condition grid specified
in the paper.

The underlying modules can also be run directly:

```bash
python -m codes.implementation_experiments --out results/implementation
python -m codes.run_all --quick --out results/nominal
python -m codes.verify_implementation --out results/audit
```

## Output correspondence

The generated file `fig2_certified_bound_final` contains the strict-FOV
certificate sweep. It uses the forward-Euler initial-condition grid specified
in the paper and compares the sampled reach with the theorem's grid-level
envelope `max(max_grid |theta0|, theta_star)`.

`w_bound_conservatism.csv` uses `theta0=0` and 81 values of
`w0 in [-W,W]` to isolate the mismatch-driven excursion associated with the
substitution `|w(t)| <= W`.

`implementation_thresholds.csv` contains the analytical bearing-error limit,
the overlap-limited effective bound, deterministic boundary-maximization
reference, and sampled-bearing age supremum.

`builder_verification.json` records the symbolic identity check,
random direct-formula comparison, barrier-inequality checks,
orientation-register independence check, cubic `k_rho` estimate, and
fixed-point residual check.

Known-good copies of the generated outputs are stored in
`reference_results/` for comparison with a fresh run.

## Scope

The implementation-level analysis certifies true-core invariance and prevention
of false measured guard activation under the deterministic bounds stated in the
paper. It does not claim full sampled-data convergence for arbitrarily stale
orientation data or a positive switching-delay margin after the unchanged FOV
guard is reached.
